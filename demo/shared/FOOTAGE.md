## Facts you may state (all measured or true; nothing else)
- Free; plugin and MCP server open source; runs **100% locally** on your own GPU; no cloud, no credits, no subscription.
- Models: NVIDIA Kimodo (motion diffusion) via kimodo.cpp (GGML, Vulkan): credit them. Text encoder built with Meta Llama 3.
- Measured on an **AMD RX 6600 XT, 8 GB**: about **20 s to generate a 5 s clip** once warm (30 diffusion steps).
- Works on **AMD, NVIDIA and Intel** (Vulkan) **in principle**: only AMD was tested. Don't claim NVIDIA/Intel were tested.
- Output: standard Unity **Humanoid AnimationClip**, so it works with Mixamo characters. Verified automatically on 4 Mixamo
  rigs and the Kenney rig, and every clip is auto-checked (facing, feet, left/right) in headless Unity.
- Agent: a local **MCP server**; works with Claude Code (or any MCP client). Claude plans shots, generates each, looks
  at the preview and redoes bad takes. Uses the person's own Claude plan; the plugin never touches credentials.
- Setup: `.\setup.ps1` (engine + models ~6 GB after accepting licenses) → add the Unity package → `claude mcp add kimodo-motion …`.
- Limits (don't hide them if asked; don't show weak cases): no fingers/face, no exact targeting yet, prompt-following imperfect.
- Product name: **Promptimate** (formerly the placeholder "Text-to-Anim"). Keep it in ONE variable.

## Do not
- Claim dancing, NVIDIA/Intel tests, speed numbers other than the one above, "mocap quality", or anything unlisted.
- Use Unity, NVIDIA, Anthropic, Meta or Adobe logos (no endorsement implied).
