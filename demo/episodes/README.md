# Shorts factory

Turns a short story spec into a finished vertical (9:16) "In this town…" animated short: narration, music, sound
effects, coloured captions, blocky Roblox-style characters acting with Promptimate motion, cut like the top shorts
online. The headless path needs no Roblox Studio: one command, about 90-120 s per 80 s episode on an RX 6600 XT once
the motion library is warm.

```powershell
.venv\Scripts\python scripts\shorts.py doctor            # check the machine
.venv\Scripts\python scripts\shorts.py produce lie_shrink # -> demo\episodes\build\lie_shrink\lie_shrink.mp4
```

Status: experimental. The best blind-judge scores are about 5/10 against 7-9 for the top reference shorts. The
Studio-rendered path scored 6.3. See "Where it stands" below.

## Setup (once per machine)

1. Do the main Promptimate setup first (`.\setup.ps1` at the repo root): the motion engine, the models and `.venv`.
2. Install the extra packages: `.venv\Scripts\python -m pip install -r requirements-shorts.txt`
3. Install **ffmpeg** with libass (any recent full build). Put it on PATH, or set `PROMPTIMATE_FFMPEG` in `local.env`.
4. Optionally copy `local.env.example` to `local.env` to move caches or tools (for example, onto a bigger drive).
5. `.venv\Scripts\python scripts\shorts.py setup` builds everything that can be rebuilt, in about a minute:
   - procedural materials, characters, props and sets in the headless cache;
   - the face textures;
   - the caption fonts (Montserrat, OFL);
   - the music and SFX listed in `media_manifest.json` (CC0/CC BY from Openverse; needs internet).
6. `.venv\Scripts\python scripts\shorts.py voice` installs the narrator in its own venv: [tiny-voca](https://github.com/n4ze3m/tiny-voca)
   (Apache-2.0, CPU torch), pinned to the version the narration was tuned on.
7. Optional: `.venv\Scripts\python scripts\shorts.py library` pre-generates the shared motion library (every in-place
   action, idle to idle). Without it, the first episodes generate their beats on the fly and are slower.
8. `scripts\shorts.py doctor` should now print `all set`. `scripts\shorts.py test` runs the fast checks.

Nothing on the offline path needs Roblox Studio, a Roblox account or any login. Every asset in the headless cache is
generated by our own code (`roblox/headless/own_*.py`, `materials.py`).

## Making an episode

1. **Write a story** in `stories/<slug>.py`. The format is documented in `writer_prompt.md`: the prompt the writer
   model (Claude Opus) gets, followed by the vocabulary from `scripts\shorts.py catalog`. In short:
   - `TITLE`, `MUSIC` (a mood), `KEYWORDS` (the caption highlights) and `CAST` (name to look);
   - `SCENES`: a set, where people stand, props and signs, and lines;
   - each line holds the narration (`say`), what people do (`do`), the magic (`change`: grow, shrink, look, swap,
     vanish, appear), camera subjects (`cam`), faces (`feel`), particles (`fx`), `sfx`, an on-screen `label`, and
     signs to `show`/`hide`.

   Copy an existing story to start. `lie_shrink.py` and `laugh_sleep.py` are the strongest so far.
2. **Produce:** `scripts\shorts.py produce <slug>`. Useful `produce.py` flags:
   - `--from record` re-renders only;
   - `--from audio` remixes only;
   - `--suffix _try2` keeps old outputs;
   - `--voice tv_F2` switches the narrator.
3. **Judge** against references, never against our own episodes. `scripts\shorts.py judge-prep OUT SEED a=x.mp4 b=y.mp4 ...`
   builds a blind kit: shuffled labels, frame sheets, cut lists, transcripts and a judge prompt. Give it to three or
   more fresh reviewers (Claude with no context), who write `OUT\verdict_<n>.json`. Then run
   `scripts\shorts.py judge-tally OUT`. Score differences under about 0.7 are noise.

## How it works

| Stage | Code | What happens |
|---|---|---|
| compile | `story_compile.py` | Turns the story into a full episode (`eps/<slug>.py`). It places the cast on stage lines facing the camera, adds crowds of extras and reaction beats for every listener, turns changes into timed events, and writes the camera subject list and caption keywords |
| pace | `produce.py` (`pace`, `tts_many`) | Narrates every line (tiny-voca `tv_M2` at 1.2x) and times the episode to the real speech |
| audio | `produce.py` (`mix`, `captions`) | Mixes voice, music and SFX to −14 LUFS, and writes word-timed coloured captions (ASS). Runs in a thread while the motion is generated |
| perform | `mcp_server/roblox_tools.py` (`perform`), `roblox/headless/stage.py` | Generates each actor's beats with Promptimate (`motiond`). In-place beats come from the shared motion library, while walks get root paths. It checks collisions against our own set geometry and regenerates beats that clip |
| direct | `roblox/headless/director.py` | Bakes every frame (poses, faces, scale, visibility, particles, signs, name tags) into `frames.npz` |
| plan | `mcp_server/roblox_record.py`, `roblox/headless/audit.py` | Plans the shots in the reference camera grammar, then audits every shot with GPU ID/depth renders (`checks.py`) for empty frames, blockers, headless crops and backs of heads, and repairs the bad ones |
| pick (optional) | `roblox/headless/shot_pick.py` | Renders 8 candidate framings per shot for a vision reviewer, and applies the picks with `PROMPTIMATE_SHOT_PICKS` |
| render | `roblox/headless/hlrender.py`, `pipeline.py` | An offscreen OpenGL renderer (moderngl) with bevel and rim shading. Foreground blockers are cleared per shot. Renders in parallel chunks, then ffmpeg muxes audio and burns in the captions |

Working data lives in the headless cache (`PROMPTIMATE_HEADLESS_CACHE`, default `.cache/headless`). Episode outputs
go to `demo/episodes/build/<slug>/`. Both are gitignored and can be rebuilt.

## Settings

Machine settings live in `local.env` (see `local.env.example`). Pipeline switches are environment variables; the
defaults are the measured best:

| Variable | Default | Meaning |
|---|---|---|
| `PROMPTIMATE_HEADLESS_CACHE` | `.cache/headless` | Headless working data |
| `PROMPTIMATE_FFMPEG` / `_FFPROBE` | PATH | Tool paths |
| `PROMPTIMATE_VENC` | auto | H.264 encoder: AMF, NVENC or QSV, else libx264 |
| `PROMPTIMATE_TINY_VOCA` | `.cache/tiny-voca` | Narrator install |
| `PROMPTIMATE_STAGE` | line | Stage-line blocking in the compiler |
| `PROMPTIMATE_CAM_STYLE` | wide | Camera grammar (lens and sizes) |
| `PROMPTIMATE_SHOT_PICKS` | unset | A `picks.json` from the vision picker |
| `PROMPTIMATE_CLEAR_FG` / `_CLEAR_PROPS` | 1 | Hide people and props between the lens and the subject |
| `PROMPTIMATE_FRONT_ARC` / `_DOP` | 1 | Camera search over the front arc, and the shot-design pass |
| `PROMPTIMATE_OWN_ASSETS` | 1 | Our own props and looks override the Studio catalog |
| `PROMPTIMATE_MOTION_LIBRARY` | 1 | In-place beats from the shared library |

## Where it stands

**Measured** in 14 blind panels (three Opus judges each, against craftee_films reference shorts):
- **Stories:** the Opus writer reaches 6-7.7, against 8-10 for the references.
- **Hooks:** about 6, since the rule is shown on screen.
- **Audio:** speech rate, pauses and loudness are inside the references' range.
- **Camera:** our weakest score at 2-4. The vision picker is worth about +0.6 overall.
- **Studio vs headless:** a Studio-rendered episode scored 6.3, so the headless look and camera cost about 1.5-3
  points.

**Open problems, most valuable first:**
1. **Close the gap with Studio**, by raising the headless look and camera, or by porting the effects (scale, signs,
   particles, extras) to the Studio player.
2. **Make transformations unmistakable on screen.**
3. **Avoid swap stories**, which always score lowest.
